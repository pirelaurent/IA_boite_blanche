Introduction aux réseaux de neurones

Un réseau de neurones transforme des données d'entrée en résultats, en propageant les valeurs de couche en couche via des opérations de pondération et de sommation.

Le perceptron simple : un réseau sans couche cachée

les propagations sont directes de la couche d'entrée vers la couche de sortie en appliquant des poids sur les entrées et en les sommant pour obtenir la sortie.

Schéma d'un perceptron simple

Les calculs sont du type : Vecteur de sortie = vecteur d'entrée × matrice de coefficients

Exemple d'application : le feu tricolore

On va créer un réseau de neurones simple qui prend en entrée un code binaire représentant un numéro de feu tricolore et qui produit en sortie un code binaire indiquant quel feu est allumé.
Entrée binaire (chiffre) Sortie Vert Orange Rouge
00 (0) 0 0 0 aucun feu
01 (1) 1 0 0 feu vert uniquement
10 (2) 1 0 0 feu orange uniquement
11 (3) 0 0 1 feu rouge uniquement
