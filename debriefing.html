Réseaux de neurones

4 concepts fondamentaux à comprendre :

Vous les avez utilisés dans l'exercice sur les réseaux de neurones !

1️⃣ Paramètres ou Poids

Les poids (notés w, pour weight) sont les paramètres ajustables d'un réseau de neurones qui :

  • Multiplient chaque entrée pour lui donner plus ou moins d'importance dans le calcul final ;
  • Déterminent la direction (+/-) de la frontière de décision dans l'espace des entrées ;
  • Sont appris pendant l'entraînement pour minimiser l'erreur du modèle ;
  • Représentent la mémoire du réseau : ils encodent ce qu'il a appris des données.

Interprétation : Un poids élevé signifie que l'entrée correspondante a un fort impact sur la décision. Un poids nul signifie que l'entrée est ignorée.

Sans poids ajustables, le réseau ne pourrait pas apprendre !

2️⃣ Biais

Le biais (noté b, pour bias) est un paramètre fondamental d'un neurone artificiel qui :

  • Décale la fonction d'activation verticalement, permettant de modifier la position de la frontière de décision ;
  • Contrôle l'intersection de la frontière avec les axes, indépendamment des poids ;
  • Permet au modèle de s'adapter même lorsque toutes les entrées sont nulles ;
  • Est appris pendant l'entraînement, au même titre que les poids.

Interprétation géométrique : Le biais déplace la frontière de décision parallèlement à elle-même dans l'espace des entrées.

Sans biais, toutes les frontières de décision passeraient par l'origine (0,0,...) !

3️⃣ Calcul (Combinaison linéaire)

Le calcul d'un neurone consiste en une combinaison linéaire pondérée des entrées, suivante :

z = (w1 × x1) + (w2 × x2) + ... + (wn × xn) + b

Où :

  • xi = valeur de l'entrée i ;
  • wi = poids associé à l'entrée i (paramètre) ;
  • b = biais (paramètre) ;
  • z = résultat de la combinaison linéaire (avant activation).

Analogie : C'est comme un produit scalaire entre le vecteur des entrées et le vecteur des poids, auquel on ajoute le biais.

Ce calcul est la base de TOUS les neurones artificiels !

4️⃣ Fonction d'activation

La fonction d'activation (notée σ ou Θ) est une fonction non-linéaire appliquée à la sortie du calcul linéaire :

sortie = σ(z) = σ((w1 × x1) + ... + b)

Rôle essentiel :

  • Introduit la non-linéarité dans le modèle, permettant de représenter des frontières de décision complexes ;
  • Sans elle, un réseau multicouche serait équivalent à un seul perceptron simple ;
  • Contrôle l'amplitude de la sortie (ex: entre 0 et 1 pour sigmoid) ;
  • Détermine le comportement du neurone (activation ou non).

Exemples de fonctions d'activation : step() (échelon), ReLU(), sigmoid(), tanh(), softmax().

La fonction d'activation est ce qui rend les réseaux de neurones puissants !

🎯 Application à votre exercice feu tricolore

Dans votre exercice, vous avez manipulé ces 4 concepts sans peut-être le réaliser ! Voici comment :

Votre neurone calcule :

sj = (b1 × w1j) + (b0 × w2j)

Puis applique une fonction d'activation step() (1 si sⱼ > seuil, 0 sinon )

Θ(sj) = step(sj - seuil)

feu_vert = Θ(s₀) = step(s₀ - seuil)
feu_orange = Θ(s₁) = step(s₁ - seuil)
feu_rouge = Θ(s₂) = step(s₂ - seuil)

Correspondance avec les concepts :

  • Poids : w1j et w2j (les valeurs que vous avez ajustées avec les boutons + et -) ;
  • Biais : b = -seuil (le seuil de 0.8 dans votre exercice équivaut à un biais de -0.8) ;
  • Calcul : sj = Σ wij × xi ;
  • Fonction d'activation : step(sj - seuil) (fonction échelon : 1 si sⱼ > seuil, 0 sinon).

Vous avez maintenant une compréhension complète des 4 piliers des réseaux de neurones !

Ces concepts sont universels et s'appliquent à tous les types de réseaux.
