Débriefing - Apprentissage des réseaux de neurones

Principe général

Chaque neurone (correspondant à un feu : vert, orange, rouge) doit apprendre à s'allumer uniquement pour son cas spécifique et rester éteint pour les autres. C'est un problème de classification : le réseau doit discriminer les 4 configurations d'entrée.

À chaque itération, l'algorithme évalue les 4 cas pour les 3 neurones, soit 12 calculs par itération (et non 16, car il y a 3 feux, pas 4 neurones).

Configuration des entrées et sorties attendues

Bouton Entrées Vert (s₁) Orange (s₂) Rouge (s₃)
0 b₁=0, b₀=0 ✓ éteint ✓ éteint ✓ éteint
1 b₁=1, b₀=0 ✓ allumé ✓ éteint ✓ éteint
2 b₁=0, b₀=1 ✓ éteint ✓ allumé ✓ éteint
3 b₁=1, b₀=1 ✓ éteint ✓ éteint ✓ allumé
Règle d'allumage : Un feu j s'allume si (b₁ × w₁ⱼ) + (b₀ × w₂ⱼ) > seuilⱼ

Exemple détaillé : apprentissage pour le feu vert

Le feu vert doit s'allumer uniquement pour le cas b₁=1, b₀=0 (bouton 1).

Cas Entrées Score vert = b₁×w₁₁ + b₀×w₂₁ Attendu Correction si erreur
0 b₁=0, b₀=0 0 × w₁₁ + 0 × w₂₁ = 0 ≤ seuil₁ (éteint) ✓ Toujours OK
1 b₁=1, b₀=0 1 × w₁₁ + 0 × w₂₁ = w₁₁ > seuil₁ (allumé) ➜ Si w₁₁ ≤ seuil₁ : augmenter w₁₁ ou diminuer seuil₁
2 b₁=0, b₀=1 0 × w₁₁ + 1 × w₂₁ = w₂₁ ≤ seuil₁ (éteint) ➜ Si w₂₁ > seuil₁ : diminuer w₂₁ ou augmenter seuil₁
3 b₁=1, b₀=1 1 × w₁₁ + 1 × w₂₁ = w₁₁ + w₂₁ ≤ seuil₁ (éteint) ➜ Si w₁₁ + w₂₁ > seuil₁ : diminuer w₁₁ et/ou w₂₁ ou augmenter seuil₁

Remarque importante : L'algorithme d'apprentissage corrige à la fois les poids ET les seuils. Pour chaque erreur, il peut choisir d'ajuster soit le poids, soit le seuil, soit les deux.

Apprentissage pour les autres feux

Feu orange (s₂)

Doit s'allumer uniquement pour b₁=0, b₀=1 (bouton 2).

  • Cas 2 : score = w₂₂ → doit être > seuil₂ ➜ si w₂₂ ≤ seuil₂ : augmenter w₂₂ ou diminuer seuil₂
  • Cas 1 : score = w₁₂ → doit être ≤ seuil₂ ➜ si w₁₂ > seuil₂ : diminuer w₁₂ ou augmenter seuil₂
  • Cas 3 : score = w₁₂ + w₂₂ → doit être ≤ seuil₂ ➜ si w₁₂ + w₂₂ > seuil₂ : diminuer w₁₂ et/ou w₂₂ ou augmenter seuil₂

Feu rouge (s₃)

Doit s'allumer uniquement pour b₁=1, b₀=1 (bouton 3).

  • Cas 3 : score = w₁₃ + w₂₃ → doit être > seuil₃ ➜ si w₁₃ + w₂₃ ≤ seuil₃ : augmenter w₁₃ et w₂₃ ou diminuer seuil₃
  • Cas 1 : score = w₁₃ → doit être ≤ seuil₃ ➜ si w₁₃ > seuil₃ : diminuer w₁₃ ou augmenter seuil₃
  • Cas 2 : score = w₂₃ → doit être ≤ seuil₃ ➜ si w₂₃ > seuil₃ : diminuer w₂₃ ou augmenter seuil₃

Interactions entre les neurones

⚠️ Attention : Comme les entrées b₁ et b₀ sont partagées entre tous les neurones, une correction pour un feu peut impacter les autres feux.

Par exemple, dans le cas 3 (b₁=1, b₀=1) :

  • Si le rouge ne s'allume pas : il faut augmenter w₁₃ et w₂₃
  • Mais si cela fait que le vert s'allume : il faut diminuer w₁₁ et w₂₁
  • Et si cela fait que l'orange s'allume : il faut diminuer w₁₂ et w₂₂

C'est pourquoi l'algorithme doit corriger toutes les erreurs simultanément, ce qui explique pourquoi on peut voir w₂₁ ou w₂₂ changer "à cause du rouge" : c'est en réalité pour maintenir l'extinction du vert et de l'orange pendant que le rouge s'allume.

Algorithme d'apprentissage

L'algorithme utilisé est basé sur la règle du perceptron :

  1. Évaluer : calculer les scores pour tous les cas et tous les neurones
  2. Détecter les erreurs : identifier quels cas ne sont pas satisfaits
  3. Corriger : pour chaque erreur, ajuster un poids ou un seuil
  4. Vérifier : accepter la correction seulement si elle n'empire pas le nombre total de cas satisfaits
  5. Répéter jusqu'à ce que tous les cas soient satisfaits ou jusqu'à la limite d'itérations

À chaque itération, l'algorithme essaie une correction à la fois, en priorisant celles qui améliorent le nombre de cas satisfaits.
