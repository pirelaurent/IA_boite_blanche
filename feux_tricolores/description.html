🎯 Introduction

Ce projet implémente un réseau de neurones artificiels de type MLP (Multi-Layer Perceptron) pour résoudre un problème de classification visuelle : reconnaître sur quelle zone tactile d'une tablette l'utilisateur a cliqué.

Objectif : Créer un système capable de classer automatiquement les coordonnées (x, y) d'un clic sur une tablette tactile en une des 4 catégories : Rouge, Vert, Bleu, ou Noir (fond).

Ce projet illustre les concepts fondamentaux des réseaux de neurones :

  • Architecture des réseaux MLP
  • Fonctions d'activation (ReLU, Sigmoïde)
  • Descente de gradient avec Adam
  • Apprentissage supervisé
  • Validation et évaluation de modèles

📐 Configuration du Problème

Tablette Tactile

  • Dimensions : 200 × 400 pixels
  • Système de coordonnées : Origine (0,0) en haut à gauche, (199,399) en bas à droite

Zones Tactiles (Cercles)

Trois cercles de couleur sont positionnés verticalement sur la tablette :

Couleur Centre (x,y) Rayon Sortie Attendue
Rouge (100, 320) 50 pixels [1, 0, 0]
Vert (100, 80) 50 pixels [0, 1, 0]
Bleu (100, 200) 50 pixels [0, 0, 1]
Noir (Fond) Partout ailleurs - [0, 0, 0]

🧠 Architecture du Réseau de Neurones

Topologie

Le réseau utilisé est un Perceptron Multi-Couche (MLP) avec l'architecture suivante : 

    ┌─────────────┐       ┌─────────────┐       ┌─────────────┐
    │   Entrée    │──────►│   Cachée    │──────►│   Sortie    │
    │   (2)       │       │   (12)      │       │   (3)       │
    └─────────────┘       └─────────────┘       └─────────────┘
          │                           │                         │
          ▼                           ▼                         ▼
        (x,y)                     ReLU                   Sigmoïde
        normalisés                 activation             activation
        [0,1]×[0,1]
Couche Nombre de neurones Fonction d'activation Rôle
Entrée 2 Linéraire Reçoit les coordonnées (x, y) normalisées
Cachée 12 (configurable : 8, 10, 12, 16, 20) ReLU Extrait des caractéristiques non-linéaires
Sortie 3 Sigmoïde Produit les probabilités pour R, V, B

Pourquoi ReLU et Sigmoïde ?

  • ReLU (Rectified Linear Unit) : f(z) = max(0, z)
    • Évite le problème du gradient évanescent
    • Permet un apprentissage plus rapide
    • Simple à calculer
    • Populaire en deep learning (depuis ~2010)
  • Sigmoïde : f(z) = 1 / (1 + e-z)
    • Produit des valeurs entre 0 et 1 (probabilités)
    • Adaptée pour la classification binaire multi-labels
    • Dérivable partout (nécessaire pour la rétropropagation)
Note : Pourquoi pas Softmax ? Softmax imposerait que la somme des sorties = 1, ce qui n'est pas adapté ici car nous voulons pouvoir avoir toutes les sorties à 0 (fond noir).

🎯 Fonctionnement du Réseau

Propagation Avant (Forward Pass)

Pour une entrée (x, y), le réseau calcule :

// Couche cachée (ReLU) z1[j] = b1[j] + Σ (x[i] × W1[i][j]) pour j = 0..11 hidden[j] = ReLU(z1[j]) = max(0, z1[j]) // Couche de sortie (Sigmoid) z2[k] = b2[k] + Σ (hidden[j] × W2[j][k]) pour k = 0..2 output[k] = σ(z2[k]) = 1 / (1 + e-z2[k])

Classification

La sortie [o0, o1, o2] est interprétée comme suit :

  • Si o0 > 0.5 : Clic dans le cercle Rouge → [1,0,0]
  • Si o1 > 0.5 : Clic dans le cercle Vert → [0,1,0]
  • Si o2 > 0.5 : Clic dans le cercle Bleu → [0,0,1]
  • Si toutes ≤ 0.5 : Clic dans le fond Noir → [0,0,0]

🔄 Apprentissage

Fonction de Coût

Le réseau utilise la Binary Cross-Entropy Loss pour chaque neurone de sortie :

LBCE(y, ŷ) = - [y × log(ŷ) + (1 - y) × log(1 - ŷ)] Où : - y : valeur attendue (0 ou 1) - ŷ : valeur prédite (entre 0 et 1) Perte totale = Moyenne des pertes sur les 3 sorties

Optimiseur : Adam

L'optimiseur Adam (Adaptive Moment Estimation) est utilisé pour mettre à jour les poids :

Paramètre Valeur Description
β1 0.9 Coefficient de la moyenne mobile exponentielle
β2 0.999 Coefficient du carré de la moyenne mobile
ε 1e-8 Petite constante pour éviter la division par zéro
Learning Rate 0.01 (configurable) Taille du pas de mise à jour

Adam combine les avantages de :

  • AdaGrad : Adaptation des taux d'apprentissage par paramètre
  • RMSProp : Normalisation par la racine carrée moyenne
  • Momentum : Accélération dans la direction des gradients persistants

Rétropropagation (Backpropagation)

L'algorithme de rétropropagation calcule les gradients de la fonction de coût par rapport à tous les poids en utilisant la règle de la chaîne :

  1. Forward Pass : Calculer les sorties du réseau
  2. Calcul de la perte : Comparer avec les valeurs attendues
  3. Backward Pass : Remonter les gradients couche par couche
  4. Mise à jour des poids : Appliquer les corrections avec Adam
💡 Insight : La rétropropagation est possible grâce aux fonctions d'activation dérivables. C'est pourquoi ReLU et Sigmoïde sont utilisées plutôt que la fonction échelon (non dérivable) du perceptron original.

📊 Dataset et Préparation des Données

Génération des Données

Le dataset est généré aléatoirement avec :

  • Points positifs : 300 points par cercle (900 total)
  • Points négatifs : 300 points dans le fond (noir)
  • Total : 1200 points d'entraînement
  • Validation : 240 points (20% du dataset)

Normalisation

Les coordonnées sont normalisées entre 0 et 1 :

xnorm = x / 199 (puisque la tablette fait 200 pixels de large) ynorm = y / 399 (puisque la tablette fait 400 pixels de haut)

La normalisation permet :

  • D'accélérer la convergence de l'apprentissage
  • D'éviter que les valeurs absolues des coordonnées n'affectent la stabilité numérique
  • De rendre les poids comparables en magnitude

✅ Évaluation et Métriques

Accuracy (Précision)

La principale métrique utilisée est l'accuracy :

Accuracy = (Nombre de prédictions correctes) / (Nombre total de prédictions)

Matrice de Confusion

La matrice de confusion permet de visualiser les performances par classe :

Vrai \ Prédit Rouge Vert Bleu Noir
Rouge TP FP FP FP
Vert FP TP FP FP
Bleu FP FP TP FP
Noir FP FP FP TP

TP = Vrai Positif, FP = Faux Positif

Précision par Classe

Pour chaque classe, on calcule :

Précision = TP / (TP + FP) = Vrais Positifs / Total des prédictions pour cette classe

🎨 Visualisation des Résultats

Après l'entraînement, plusieurs visualisations sont disponibles :

  • Carte des prédictions : Une grille où chaque pixel montre la couleur prédite par le réseau pour cette position. Permet de voir les frontières apprises.
  • Graphiques d'entraînement : Courbes de perte et de précision sur les jeux d'entraînement et de validation.
  • Test de points spécifiques : Permet de tester manuellement des coordonnées pour vérifier la prédiction.

📦 Résultats Attendus

Avec une architecture MLP 2-12-3 et un entraînement adéquat, on peut s'attendre à :

Taille couche cachée Précision attendue Temps d'entraînement Remarques
8 neurones ~90-93% 0.5-1s Minimal, frontières approximatives
10 neurones ~95-97% 0.7-1.2s Bon compromis
12 neurones ~96-98% 1-1.5s Recommandé
16 neurones ~95-97% 1.5-2s Peut surapprendre
20+ neurones ~95-98% 2-3s+ Surapprentissage probable
💡 Remarque : Les résultats peuvent varier légèrement selon l'initialisation aléatoire des poids. La normalisation et l'utilisation d'Adam permettent une convergence rapide et stable dans la plupart des cas.

🔧 Configuration Recommandée

Pour obtenir de bons résultats rapidement :

  • Taille couche cachée : 12 neurones
  • Nombre d'époques : 2000
  • Taille du batch : 32
  • Taux d'apprentissage : 0.01
  • Optimiseur : Adam (β1=0.9, β2=0.999)
  • Fonction de coût : Binary Cross-Entropy

Avec ces paramètres, l'entraînement devrait prendre environ 1-2 secondes et atteindre une précision de 96-98% sur le jeu de validation.

🚀 Aller Plus Loin

Ce projet peut être étendu de plusieurs manières :

  • Ajouter plus de couleurs : Modifier le code pour supporter 4 ou 5 cercles de couleurs différentes.
  • Changer la géométrie : Utiliser des carrés, des triangles ou d'autres formes au lieu de cercles.
  • Augmenter la complexité : Ajouter une deuxième couche cachée pour créer un réseau plus profond.
  • Autres optimiseurs : Tester SGD, RMSProp, ou AdaGrad et comparer les performances avec Adam.
  • Regularisation : Ajouter du dropout ou de la régularisation L2 pour prévenir le surapprentissage.
  • Data Augmentation : Générer plus de données avec des variations pour améliorer la robustesse.
