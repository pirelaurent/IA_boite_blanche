Feux tricolores - Tablette tactile et réseau de neurones

1. Configuration du problème

Tablette tactile

Une tablette de 200 × 400 pixels avec trois cercles tactiles :

  • Vert : (x=100, y=80), rayon = 50px
  • Orange : (x=100, y=200), rayon = 50px
  • Rouge : (x=100, y=320), rayon = 50px
Les cercles sont distribués verticalement : Vert centré sur y=80, Rouge sur y=320, et Orange à mi-hauteur (y=200). Espacement de 20px entre les bords des cercles (distance entre centres = 120px).

Comportement

L'appui sur un cercle active une action spécifique :
CercleCouleurActionSortie
1VertAllumer vert[1,0,0]
2OrangeAllumer orange[0,1,0]
3RougeAllumer rouge[0,0,1]
-AilleursÉteindre tout[0,0,0]

Encodage des sorties : Chaque sortie correspond à une couleur. Sortie = 1 → la couleur est allumée.
Sortie = 0 → la couleur est éteinte.
[0,0,0] → toutes les couleurs sont éteintes.

Schéma de la tablette

Figure 1 : Disposition des 3 cercles tactiles sur la tablette 200×400 pixels. Vert centré à y=80, Rouge à y=320, Orange à mi-hauteur (y=200). Rayon de chaque cercle : 50 pixels.

Remarque : Avec un rayon de 50 pixels et un espacement de 50 pixels entre les bords, la distance entre centres est de 100 pixels. Les centres sont positionnés à y=100, y=200 et y=300.

2. Architecture du réseau de neurones

Topologie

Réseau MLP (Multi-Layer Perceptron) avec :
  • Couche d'entrée : 2 neurones (x, y)
  • Couche cachée : 12 neurones
  • Couche de sortie : 3 neurones (Vert, Orange, Rouge)

    • Fonctions d'activation

    Choix optimaux pour ce problème de classification non-linéaire :
  • Couche cachée : ReLU (Rectified Linear Unit)

    Évite le problème du gradient évanescent et permet un apprentissage plus rapide.

  • Couche de sortie : Sigmoïde

    Produit des valeurs entre 0 et 1 pour chaque sortie, adaptée aux étiquettes binaires.

    Pourquoi pas Softmax ? Softmax imposerait que la somme des sorties = 1, ce qui n'est pas adapté ici : on veut pouvoir avoir toutes les sorties à 0 (éteindre tout) ou une seule à 1 (allumer une couleur).

    Schéma du réseau

    Entrée 2 neurones Cachée 12 neurones ReLU V O R Sortie 3 neurones Sigmoïde Figure 2 : Architecture du réseau MLP 2-12-3 avec fonctions d'activation ReLU (cachée) et Sigmoïde (sortie).

    Fonctionnement mathématique

    Pour une entrée (x, y) normalisée dans [0,1] :

    // Couche cachée (12 neurones avec ReLU)
    hidden = ReLU(W₁·[x,y]ᵀ + b₁) // W₁ : matrice 12×2, b₁ : vecteur 12

    // Couche de sortie (3 neurones avec Sigmoïde)
    output = σ(W₂·hidden + b₂) // W₂ : matrice 3×12, b₂ : vecteur 3

    // ReLU(z) = max(0, z)
    // σ(z) = 1 / (1 + exp(-z))

    3. Constitution du jeu de données

    Problématique

    La tablette compte 200 × 400 = 80 000 pixels. Tester toutes les positions est :
    • Calculatoirement coûteux : 80 000 itérations par epoch
    • Redondant : Les pixels voisins donnent des sorties très similaires
    • Innécessaire : Le réseau peut généraliser à partir d'un échantillonnage représentatif

    Stratégie d'échantillonnage

    Taille du jeu d'entraînement

    1 200 échantillons au total : CatégorieNombre% du total Vert30025% Orange30025% Rouge30025% Ailleurs30025% Total1 200100% Équilibrage des classes : Chaque catégorie (3 cercles + extérieur) a le même nombre d'échantillons pour éviter un biais d'apprentissage.

    Méthode de génération

    Pour chaque cercle :
    1. Définir un carré englobant (100×100 pixels)
    2. Générer 300 points aléatoires dans ce carré
    3. Filtrer : ne garder que les points dans le cercle
    4. Répéter jusqu'à obtenir 300 points valides
    Pour l'extérieur :
  • Générer des points aléatoires sur toute la tablette
  • Rejeter ceux qui tombent dans un cercle
  • Jusqu'à obtenir 300 points

    • Jeu de validation (Validation Set)

    240 échantillons (20% du dataset total de 1 440) générés avec la même méthode mais avec une graine aléatoire différente. Composition :
  • 60 points par cercle (180 total)
  • 60 points en dehors des cercles

    4. Entraînement du réseau

    Paramètres d'apprentissage

    ParamètreValeurJustification Fonction de coût Binary Cross-Entropy Adaptée aux sorties binaires indépendantes Optimiseur Adam Adaptatif, efficace pour ce type de problème Taux d'apprentissage 0.01 Valeur standard pour Adam Nombre d'epochs 500-1000 Suffisant pour converger Taille batch 32 Mini-batch pour l'optimisation

    Normalisation des entrées

    Les coordonnées (x, y) sont normalisées entre [0, 1] :
    x_normalisé = x / 199 // 0 ≤ x ≤ 199
    y_normalisé = y / 399 // 0 ≤ y ≤ 399 Cela améliore la convergence de l'algorithme d'optimisation.

    Encodage des sorties

    Chaque classe est représentée par un vecteur de 3 dimensions : Vert : [1, 0, 0] // Allumer vert
    Orange : [0, 1, 0] // Allumer orange
    Rouge : [0, 0, 1] // Allumer rouge
    Ailleurs: [0, 0, 0] // Éteindre tout

    Processus d'entraînement

    L'algorithme suit ces étapes :
    1. Initialisation : Poids aléatoires (Xavier/Glorot)
    2. Forward Pass : Calculer les prédictions du réseau
    3. Calcul de la perte : Binary Cross-Entropy entre prédiction et cible
    4. Backpropagation : Calculer les gradients par rapport aux poids
    5. Mise à jour des poids : Utiliser Adam avec le gradient
    6. Répéter pour tous les échantillons du batch, puis pour tous les epochs

    Validation : Après chaque epoch, évaluer le réseau sur le jeu de validation pour détecter le overfitting. Si l'erreur de validation commence à augmenter alors que l'erreur d'entraînement diminue encore, il faut arrêter l'entraînement (early stopping).

    5. Évaluation attendue

    Métriques

    Après entraînement, on évalue :
  • Accuracy : % de prédictions correctes (toutes les sorties exactes)
  • Precision/Recall par classe : Performance individuelle pour chaque cercle
  • Matrice de confusion : Visualisation des erreurs entre classes

    • Visualisation de la frontière de décision

    On peut afficher :
  • La tablette avec une grille de prédictions du réseau
  • Les régions prédites pour chaque classe
  • Comparaison avec les cercles réels
    • Le réseau devrait apprendre à approximer les 3 cercles avec ses frontières non-linéaires, bien que la forme ne soit pas parfaitement circulaire (limitation des réseaux MLP).

    Attentes

    Avec 12 neurones dans la couche cachée, le réseau devrait atteindre :
  • Accuracy > 95% sur le jeu d'entraînement
  • Accuracy > 90% sur le jeu de validation
  • Une bonne généralisation aux points non vus
