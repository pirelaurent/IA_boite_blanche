Projet Feux Tricolores

Exemple concret d'application d'un réseau de neurones MLP pour la classification de points sur une tablette tactile avec 4 cercles tactiles (noir, vert, orange, rouge).

📋 Description

Description détaillée du problème, de l'architecture du réseau, de la constitution du dataset et des paramètres d'entraînement.

Contenu :
  • Configuration de la tablette tactile 200×400
  • Positionnement des 4 cercles (rayon 30, espacés de 15px)
  • Architecture MLP 2-12-4
  • Stratégie de constitution du dataset
  • Paramètres d'entraînement
  • Figures explicatives SVG

🧠 Entraînement

Implémentation interactive du réseau de neurones avec entraînement en JavaScript pur (sans framework). Fonctionnalités :
  • Génération du dataset (1 800 échantillons)
  • Entraînement avec Adam et Binary Cross-Entropy
  • Visualisation des frontières de décision
  • Matrice de confusion
  • Test de points spécifiques
  • Export/Import du modèle
    • Lancer l'entraînement

    Résumé technique

    Ce projet illustre un réseau de neurones MLP pour classer les appuis sur une tablette tactile en 5 catégories :

    AspectValeur
    Tablette200×400 pixels
    Cercles4 × rayon 30px, espacés de 15px
    RéseauMLP 2-12-4
    ActivationsReLU (cachée), Sigmoïde (sortie)
    Dataset1 500 entraînement + 300 validation
    OptimiseurAdam
    Fonction coûtBinary Cross-Entropy

    Comment utiliser

    1. Lire la description : Comprendre le problème et la méthode proposée
    2. Générer le dataset : Cliquer sur le bouton pour créer les échantillons
    3. Visualiser le dataset : Vérifier la distribution des points
    4. Entraîner le réseau : Configurer les paramètres et lancer l'entraînement
    5. Analyser les résultats : Visualiser les prédictions et la matrice de confusion
    6. Tester manuellement : Entrer des coordonnées pour vérifier le comportement

    Note : L'entraînement s'exécute dans le navigateur et peut prendre quelques minutes selon la configuration. Utilisez Chrome ou Firefox pour de meilleures performances.
