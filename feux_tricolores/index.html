🎯 Feux Tricolores RGB - Réseau de Neurones

📊 Description du Problème

Ce projet implémente un réseau de neurones MLP (Multi-Layer Perceptron) pour classer les zones tactiles d'une tablette de 200×400 pixels.

Configuration de la tablette :

  • Dimensions : 200 × 400 pixels
  • 3 zones tactiles circulaires :
    • Rouge : centre à (100, 320), rayon 50px
    • Vert : centre à (100, 80), rayon 50px
    • Bleu : centre à (100, 200), rayon 50px
  • Fond : Noir (quand on clique en dehors des cercles)

Le réseau doit apprendre à associer chaque coordonnée (x,y) à la bonne couleur :

Position Couleur Sortie du réseau
Dans le cercle Rouge ⬤ Rouge [1, 0, 0]
Dans le cercle Vert ⬤ Vert [0, 1, 0]
Dans le cercle Bleu ⬤ Bleu [0, 0, 1]
Ailleurs (fond) ⬤ Noir [0, 0, 0]

🧠 Architecture du Réseau

Topologie

  • Couche d'entrée : 2 neurones (x, y normalisés dans [0, 1])
  • Couche cachée : 12 neurones avec activation ReLU
  • Couche de sortie : 3 neurones avec activation Sigmoïde

Pourquoi ces choix ?

  • ReLU : Évite le problème du gradient évanescent et permet un apprentissage plus rapide
  • Sigmoïde : Produit des valeurs entre 0 et 1 pour chaque sortie
  • 12 neurones cachés : Suffisant pour approximer les 3 frontières circulaires

Diagramme du réseau

  Input Layer (2)       Hidden Layer (12)       Output Layer (3)
  ───────────────        ─────────────────        ───────────────

                  │                    │         ► V (Vert)
                  │   ReLU            │ Sigmoid  │
                  │                    │         ► B (Bleu)
